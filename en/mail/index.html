VoxRox Mail

An email client for people who read the screen with a screen reader and work by keyboard. It is written by someone who works with a screen reader every day, and tested with NVDA and JAWS.

Go to download

Built for a screen reader

  • Message and contact lists are grids you move through with the arrow keys, each cell saying what its column holds.
  • The keyboard shortcuts follow Microsoft Outlook, so the habits you have from work carry over. The full list is in the app under Settings → Keyboard shortcuts.
  • Tested with the NVDA and JAWS screen readers on Windows.
  • The accessibility target is WCAG 2.2 Level AA.

The accounts you have

The add-account wizard recognises your provider from the address and offers only what works there.

  • Gmail and Google Workspace with an app password. Signing in through Google works only for accounts on the tester list until Google verifies the app.
  • Outlook.com, Hotmail and Microsoft 365 by signing in with your Microsoft account.
  • Seznam.cz with your account password, or an app password if two-step verification is on.
  • Any other provider or your own server over IMAP and SMTP.

Your mail stays on your computer

Accounts, messages and contacts live in a database on your disk, and VoxRox runs no server your mail would pass through. The app collects no telemetry, analytics or crash reports. Remote images in a message stay blocked until you allow them. The details are in the privacy policy.

What else it does

  • Conversations, or one message at a time.
  • Drafts, replies and forwarding; addresses are suggested from your contacts and from the mail you have exchanged.
  • Markdown in an ordinary text field: the recipient gets a formatted message, and if you do not use Markdown, nothing changes for you.
  • Contacts with your own labels and vCard export.
  • Runs in the notification area and announces new mail through Windows notifications.
  • Czech and English interface, light and dark themes.
  • Updates that install from inside the app, each one's signature checked before it installs.

Download and install

The installer for 64-bit Windows is on the latest release page on GitHub. Installing needs no administrator rights, and there is nothing else to install, Java included.

Download for Windows
  • The installer is not signed yet, so Windows reports an unknown publisher. How to verify the downloaded file before running it is described in Verifying the installer; how releases will be signed is in the code signing policy.
  • Betas with new features keep coming: to get them earlier, set Settings → About → Update channel to Beta in the app.

Free and open

VoxRox Mail is open source under the MIT license, and its source code is on GitHub. Ideas for new features go to the Ideas discussions, bugs to Issues or to info@voxrox.org. What to send so we can help is on the Support page.
